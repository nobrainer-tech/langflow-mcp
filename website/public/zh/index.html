01 / 功能

从已保存的流程，到实际结果。

此仓库将 Langflow 操作转换为 MCP 工具。可以使用独立工具，也可以选择更精简的、基于操作的接口。

01

流程与项目

查找、创建、更新和整理流程，进行导入、导出与版本管理。

02

执行与人工决策

运行工作流，检查结果，并在人工决策后恢复暂停的任务。

03

知识与记忆

管理知识库、数据导入和记忆功能。可用性取决于 Langflow 配置。

04

模型与策略

查看模型提供商与策略。管理操作使用你的 Langflow 权限。

05

监控

检查消息、会话和执行记录，查询服务健康及就绪状态。

06

智能体与 A2A

使用智能体助手及 Agent-to-Agent 接口，需要先在 Langflow 服务器上启用。

03 / 安装

从你自己的 Langflow 开始。

需要 Node.js 20+、运行中的 Langflow 实例及其 API 密钥。请从源码构建，以使用本页介绍的功能。

仓库版本：4.12.0 · 本页发布时 npm latest 为 4.11.0。npm 包尚未包含这里展示的全部功能。请在 npm 查看最新发布版本。 npm ↗

01 / 从源码构建

git clone https://github.com/nobrainer-tech/langflow-mcp.git
cd langflow-mcp
npm ci
npm run build

02 / 连接客户端

在本地替换示例地址和 API 密钥，并在克隆的仓库目录中运行客户端命令。不要将密钥提交到 Git。

Codex

codex mcp add langflow \
  --env LANGFLOW_BASE_URL=http://localhost:7860 \
  --env LANGFLOW_API_KEY=YOUR_LANGFLOW_API_KEY \
  --env LANGFLOW_CONSOLIDATED_TOOLS=true \
  -- node "$PWD/dist/mcp/index.js"

Claude Code

claude mcp add langflow \
  -e LANGFLOW_BASE_URL=http://localhost:7860 \
  -e LANGFLOW_API_KEY=YOUR_LANGFLOW_API_KEY \
  -e LANGFLOW_CONSOLIDATED_TOOLS=true \
  -- node "$PWD/dist/mcp/index.js"

服务器部署在其他机器上？

仓库还支持 /mcp 路径上的 Streamable HTTP。远程部署请使用 HTTPS 和 bearer 身份验证。配置详情见 README。

04 / FAQ

你可能想了解。

这是 Langflow 本身吗？

不是。它是连接现有 Langflow 实例的开源 MCP 桥接服务。Langflow 需要单独运行和配置。

支持哪些客户端？

仓库提供 Codex、Claude Code 和 Claude Desktop 的配置说明。其他客户端需要兼容 MCP stdio 或 Streamable HTTP。并非所有客户端都经过端到端测试。

它可以修改或删除数据吗？

可以。部分工具会修改流程、项目和管理设置。请检查请求的操作，并使用权限适当的 API 密钥。

流式结果会实时显示吗？

部分上游接口使用 SSE。目前客户端会缓冲返回文本，而不是逐个实时呈现事件。
