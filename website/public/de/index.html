03 / Installation

Starte mit deinem eigenen Langflow.

Du brauchst Node.js 20+, eine laufende Langflow-Instanz und ihren API-Schlüssel. Baue den Server aus dem Quellcode für die hier beschriebenen Funktionen.

Repository: 4.12.0 · npm latest: 4.11.0 bei Veröffentlichung dieser Seite. Das npm-Paket enthält noch nicht alle gezeigten Funktionen. Prüfe den aktuellen Stand auf npm. npm ↗

01 / Aus Quellcode bauen

git clone https://github.com/nobrainer-tech/langflow-mcp.git
cd langflow-mcp
npm ci
npm run build

02 / Client verbinden

Beispiel-URL und API-Schlüssel lokal ersetzen. Client-Befehl im geklonten Repository ausführen. Schlüssel niemals in Git speichern.

Codex

codex mcp add langflow \
  --env LANGFLOW_BASE_URL=http://localhost:7860 \
  --env LANGFLOW_API_KEY=YOUR_LANGFLOW_API_KEY \
  --env LANGFLOW_CONSOLIDATED_TOOLS=true \
  -- node "$PWD/dist/mcp/index.js"

Claude Code

claude mcp add langflow \
  -e LANGFLOW_BASE_URL=http://localhost:7860 \
  -e LANGFLOW_API_KEY=YOUR_LANGFLOW_API_KEY \
  -e LANGFLOW_CONSOLIDATED_TOOLS=true \
  -- node "$PWD/dist/mcp/index.js"

Server auf einem anderen Rechner?

Das Repository unterstützt auch Streamable HTTP unter /mcp. Nutze HTTPS und Bearer-Authentifizierung für eine entfernte Bereitstellung. Die README enthält die Einrichtung.

04 / FAQ

Gut zu wissen.

Ist das Langflow selbst?

Nein. Dies ist eine quelloffene MCP-Brücke zu deiner vorhandenen Langflow-Instanz. Langflow wird separat eingerichtet.

Welche Clients sind geeignet?

Das Repository dokumentiert Codex, Claude Code und Claude Desktop. Andere Clients benötigen kompatibles MCP stdio oder Streamable HTTP. Nicht jeder Client wurde durchgängig getestet.

Können Daten geändert oder gelöscht werden?

Ja. Einige Tools ändern Flows, Projekte und administrative Einstellungen. Prüfe Aktionen und verwende einen passend berechtigten API-Schlüssel.

Werden Streaming-Ergebnisse live angezeigt?

Einige Endpunkte verwenden SSE. Der Client puffert deren Text derzeit, statt jedes Ereignis einzeln weiterzugeben.
