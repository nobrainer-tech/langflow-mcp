03 / Instalación

Empieza con tu propio Langflow.

Necesitas Node.js 20+, una instancia de Langflow en ejecución y su clave API. Compila desde el código fuente para obtener las funciones descritas aquí.

Repositorio: 4.12.0 · npm latest: 4.11.0 al publicar esta página. El paquete npm aún no incluye todas las funciones mostradas. Consulta npm para ver la versión actual. npm ↗

01 / Compila el código fuente

git clone https://github.com/nobrainer-tech/langflow-mcp.git
cd langflow-mcp
npm ci
npm run build

02 / Conecta tu cliente

Sustituye la URL y la clave API de ejemplo localmente. Ejecuta el comando del cliente desde el repositorio clonado. No guardes tu clave en Git.

Codex

codex mcp add langflow \
  --env LANGFLOW_BASE_URL=http://localhost:7860 \
  --env LANGFLOW_API_KEY=YOUR_LANGFLOW_API_KEY \
  --env LANGFLOW_CONSOLIDATED_TOOLS=true \
  -- node "$PWD/dist/mcp/index.js"

Claude Code

claude mcp add langflow \
  -e LANGFLOW_BASE_URL=http://localhost:7860 \
  -e LANGFLOW_API_KEY=YOUR_LANGFLOW_API_KEY \
  -e LANGFLOW_CONSOLIDATED_TOOLS=true \
  -- node "$PWD/dist/mcp/index.js"

¿El servidor está en otra máquina?

El repositorio también admite Streamable HTTP en /mcp. Usa HTTPS y autenticación bearer para un despliegue remoto. La configuración se explica en el README.

04 / FAQ

Lo que conviene saber.

¿Esto es Langflow?

No. Es un puente MCP de código abierto hacia tu instancia de Langflow. Langflow se ejecuta y configura por separado.

¿Qué clientes se pueden conectar?

El repositorio documenta Codex, Claude Code y Claude Desktop. Otros clientes necesitan compatibilidad con MCP stdio o Streamable HTTP. No todos los clientes se han probado de extremo a extremo.

¿Puede modificar o borrar datos?

Sí. Algunas herramientas modifican flujos, proyectos y ajustes administrativos. Revisa las acciones y usa una clave API con los permisos adecuados.

¿Se muestran los resultados en tiempo real?

Varios endpoints usan SSE. El cliente almacena su texto temporalmente en lugar de mostrar cada evento de forma incremental.
