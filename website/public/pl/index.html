01 / Możliwości

Od zapisanego flow do wyniku.

Repozytorium udostępnia operacje Langflow jako narzędzia MCP. Wybierz pojedyncze narzędzia lub mniejszy interfejs oparty na akcjach.

01

Flow i projekty

Wyszukuj, twórz, aktualizuj i porządkuj flow. Importuj, eksportuj i zarządzaj wersjami.

02

Uruchomienia i decyzje

Uruchamiaj procesy, sprawdzaj wyniki i wznawiaj zadania oczekujące na decyzję człowieka.

03

Wiedza i pamięć

Zarządzaj bazami wiedzy, importem danych i pamięcią. Dostępność zależy od konfiguracji Langflow.

04

Modele i polityki

Przeglądaj dostawców modeli i polityki. Zmiany administracyjne korzystają z uprawnień w Langflow.

05

Monitoring

Sprawdzaj wiadomości, sesje i ślady wykonania. Kontroluj stan oraz gotowość serwera.

06

Agenci i A2A

Korzystaj z asystenta i interfejsów Agent-to-Agent, jeśli włączono je na serwerze Langflow.

03 / Instalacja

Zacznij od własnego Langflow.

Potrzebujesz Node.js 20+, działającej instancji Langflow i jej klucza API. Zbuduj serwer ze źródeł, aby uzyskać opisane tu możliwości.

Repozytorium: 4.12.0 · npm latest: 4.11.0 w chwili publikacji strony. Paczka npm nie zawiera jeszcze wszystkich pokazanych funkcji. Sprawdź aktualne wydanie w npm. npm ↗

01 / Zbuduj ze źródeł

git clone https://github.com/nobrainer-tech/langflow-mcp.git
cd langflow-mcp
npm ci
npm run build

02 / Połącz klienta

Podmień przykładowy adres i klucz API lokalnie. Polecenie klienta uruchom z katalogu sklonowanego repozytorium. Nie zapisuj klucza w Git.

Codex

codex mcp add langflow \
  --env LANGFLOW_BASE_URL=http://localhost:7860 \
  --env LANGFLOW_API_KEY=YOUR_LANGFLOW_API_KEY \
  --env LANGFLOW_CONSOLIDATED_TOOLS=true \
  -- node "$PWD/dist/mcp/index.js"

Claude Code

claude mcp add langflow \
  -e LANGFLOW_BASE_URL=http://localhost:7860 \
  -e LANGFLOW_API_KEY=YOUR_LANGFLOW_API_KEY \
  -e LANGFLOW_CONSOLIDATED_TOOLS=true \
  -- node "$PWD/dist/mcp/index.js"

Serwer na innej maszynie?

Repozytorium obsługuje także Streamable HTTP pod /mcp. Zdalne wdrożenie wymaga HTTPS i uwierzytelnienia bearer. Szczegóły konfiguracji znajdziesz w README.

04 / FAQ

Co warto wiedzieć.

Czy to samo Langflow?

Nie. To otwarty most MCP do istniejącej instancji Langflow. Langflow uruchamiasz i konfigurujesz osobno.

Jakie klienty można podłączyć?

Repozytorium opisuje Codex, Claude Code i Claude Desktop. Inne klienty potrzebują zgodnej obsługi MCP stdio lub Streamable HTTP. Nie każdy klient został przetestowany od początku do końca.

Czy serwer może zmieniać lub usuwać dane?

Tak. Niektóre narzędzia zmieniają flow, projekty i ustawienia administracyjne. Sprawdzaj żądane akcje i stosuj klucz API z odpowiednimi uprawnieniami.

Czy strumień wyników jest widoczny na żywo?

Część endpointów korzysta z SSE. Klient obecnie buforuje ich tekst, zamiast udostępniać każde zdarzenie na bieżąco.
