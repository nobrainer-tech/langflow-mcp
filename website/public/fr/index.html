03 / Installation

Commencez avec votre propre Langflow.

Il vous faut Node.js 20+, une instance Langflow active et sa clé API. Compilez depuis les sources pour obtenir les fonctionnalités décrites ici.

Dépôt : 4.12.0 · npm latest : 4.11.0 à la publication de cette page. Le paquet npm ne comprend pas encore toutes les fonctions présentées. Consultez npm pour la version actuelle. npm ↗

01 / Compiler les sources

git clone https://github.com/nobrainer-tech/langflow-mcp.git
cd langflow-mcp
npm ci
npm run build

02 / Connecter votre client

Remplacez localement l’URL et la clé API d’exemple. Exécutez la commande du client depuis le dépôt cloné. Ne stockez jamais votre clé dans Git.

Codex

codex mcp add langflow \
  --env LANGFLOW_BASE_URL=http://localhost:7860 \
  --env LANGFLOW_API_KEY=YOUR_LANGFLOW_API_KEY \
  --env LANGFLOW_CONSOLIDATED_TOOLS=true \
  -- node "$PWD/dist/mcp/index.js"

Claude Code

claude mcp add langflow \
  -e LANGFLOW_BASE_URL=http://localhost:7860 \
  -e LANGFLOW_API_KEY=YOUR_LANGFLOW_API_KEY \
  -e LANGFLOW_CONSOLIDATED_TOOLS=true \
  -- node "$PWD/dist/mcp/index.js"

Le serveur est sur une autre machine ?

Le dépôt prend aussi en charge Streamable HTTP sur /mcp. Utilisez HTTPS et l’authentification bearer pour un déploiement distant. Le README explique la configuration.

04 / FAQ

Quelques points à connaître.

Est-ce Langflow lui-même ?

Non. C’est une passerelle MCP open source vers votre instance Langflow existante. Langflow s’exécute et se configure séparément.

Quels clients peuvent se connecter ?

Le dépôt documente Codex, Claude Code et Claude Desktop. Les autres clients doivent prendre en charge MCP stdio ou Streamable HTTP. Tous les clients n’ont pas été testés de bout en bout.

Peut-il modifier ou supprimer des données ?

Oui. Certains outils modifient les flux, les projets et les paramètres administratifs. Vérifiez les actions et utilisez une clé API avec les permissions appropriées.

Les résultats sont-ils diffusés en direct ?

Plusieurs endpoints utilisent SSE. Le client met actuellement leur texte en mémoire tampon plutôt que de présenter chaque événement de manière incrémentale.
